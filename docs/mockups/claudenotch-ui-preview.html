Compact-count logic (from NotchCompactView): the pill shows 🟠{waiting} where waiting = needsPermission + needsInput, then 🔵{working}. So a session that “needs input” (🟡 when expanded) is folded into the 🟠 count in the pill. done / failed / ended never appear in the pill — you only see them on hover. Trailing side is empty (compactTrailing = EmptyView).
